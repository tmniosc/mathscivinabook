# mathscivinabook

Tủ sách Toán – Khoa học tiếng Việt: tuyển tập **70 đầu sách PDF** về toán phổ thông & toán olympiad, toán học đại chúng, vật lý đại chúng, khoa học máy tính và triết học.

Kho sách được sưu tầm nhằm mục đích **lưu trữ và tự học**, chủ yếu là các bản dịch tiếng Việt của những cuốn sách phổ biến khoa học kinh điển (Polya, Simon Singh, Trịnh Xuân Thuận, Ian Stewart, Michio Kaku, Brian Greene…) cùng một số tài liệu bồi dưỡng học sinh giỏi trong nước.

## Cách sử dụng

### Tải toàn bộ kho sách

```bash
git clone https://github.com/tmniosc/mathscivinabook.git
```

> ⚠️ Kho sách nặng khoảng **1.15 GB**. Nếu chỉ cần vài cuốn, hãy tải trực tiếp từng tệp trên giao diện web GitHub (mở tệp PDF → nút **Download**) thay vì clone toàn bộ.

### Tải một thư mục chủ đề (sparse checkout)

Chỉ lấy riêng phần vật lý đại chúng chẳng hạn:

```bash
git clone --filter=blob:none --sparse https://github.com/tmniosc/mathscivinabook.git
cd mathscivinabook
git sparse-checkout set popular_physic
```

## Đóng góp

Rất hoan nghênh các đóng góp giúp kho sách đầy đủ và chính xác hơn:

- **Bổ sung sách mới** — đặt tệp vào đúng thư mục chủ đề, rồi cập nhật bảng danh mục tương ứng trong README.
- **Sửa thông tin** — tên sách, tác giả, dịch giả, năm xuất bản chưa đúng.
- **Cải thiện chất lượng** — thay thế bản scan mờ bằng bản rõ hơn, bản có OCR (tìm kiếm được chữ trong PDF).
- **Đặt tên tệp thống nhất** — khuyến khích theo mẫu `Tên sách - Tác giả.pdf`.

Nếu muốn thêm một chủ đề mới (ví dụ `chemistry/`, `biology/`), hãy tạo thư mục mới và thêm một mục tương ứng trong README.

### Ghi chú kỹ thuật

GitHub **chặn cứng** mọi tệp lớn hơn 100 MB khi push qua Git thường. Ban đầu có hai cuốn vượt ngưỡng này, nên chúng đã được nén lại:

| Tệp | Trước | Sau |
|---|---:|---:|
| `popular_physic/[Ebook] Hiểu Biết Về Khoa Học - How Science Works.pdf` | 254.7 MB | **89.5 MB** |
| `popular_mathematics/sangtaotoanhoc.pdf` | 132.2 MB | **83.1 MB** |

Cả hai đều là **PDF scan thuần ảnh** (mỗi trang là một ảnh JPEG, chiếm 99–100% dung lượng tệp), nên cách nén là giảm độ phân giải và nén lại ảnh JPEG của từng trang:

- *How Science Works* — sách màu minh họa: thu nhỏ còn 65%, JPEG quality 58 (≈ 1420 × 1745 px/trang)
- *Sáng tạo toán học* — sách chữ đen trắng: thu nhỏ còn 72%, JPEG quality 56 (≈ 1430 × 2020 px/trang)

Số trang, kích thước trang và cấu trúc tài liệu được giữ nguyên; chỉ luồng ảnh bên trong bị thay. Ở mức phóng to thông thường, chữ (kể cả dấu tiếng Việt) và hình minh họa vẫn rõ ràng. Nếu bạn cần bản scan gốc độ phân giải đầy đủ, xin mở issue.

Sau khi nén, tệp lớn nhất kho là 95.4 MB — vẫn dưới ngưỡng, nên **không cần Git LFS**. Lưu ý GitHub vẫn hiển thị cảnh báo với tệp trên 50 MB (8 tệp), nhưng đây chỉ là cảnh báo, không chặn push.

Nếu thấy cuốn nào hữu ích, hãy cân nhắc **mua bản in chính thức** để ủng hộ tác giả, dịch giả và nhà xuất bản.
